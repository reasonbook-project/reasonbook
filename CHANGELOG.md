# Changelog

All notable changes to Reasonbook are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-01

### Added

- Initial open-source release of Reasonbook.
- Decision lifecycle management.
- Matters and awards tracking.
- Alerts and signals.
- Oversight and findings.
- Hash-chained integrity with `verify_integrity`.
- USAspending CSV import.
- Connector framework (USAspending only).
- Single-admin local authentication.
- Local-storage attachments.
- SQLite by default with optional PostgreSQL support.
- In-process APScheduler ingestion.
- React/TypeScript single-page application.
