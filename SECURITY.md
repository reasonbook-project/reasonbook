# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a vulnerability

Please report security vulnerabilities privately by emailing
opensource@datavisuals.com. Do not open public issues for security reports.

Include steps to reproduce the issue so we can validate and address it
quickly. We aim to acknowledge your report within a few business days and
will keep you informed as we work on a fix.
